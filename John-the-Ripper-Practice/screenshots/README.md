# Screenshots

Drop your lab screenshots into the matching numbered subfolder as you complete each stage. Suggested naming: `short-description.png` (lowercase, hyphens).

- `01-installation/` — install verification, `--version`, `--list=formats`
- `02-basic-cracking/` — Lab 1 single-crack mode
- `03-wordlist-attacks/` — Lab 2 rockyou/wordlist runs
- `04-rules-and-modes/` — Lab 3 rule-based mangling
- `05-hash-formats/` — Lab 4 zip2john/office2john extraction + cracking
- `06-real-world-labs/` — Lab 5 end-to-end CTF-style walkthrough

Each `.gitkeep` file just keeps the empty folder tracked by git — delete it once you add real screenshots to that folder (or leave it, git ignores it either way).

**Before uploading a screenshot:** crop out anything sensitive (real IPs you don't control, unrelated terminal history, personal file paths you'd rather not share publicly).
